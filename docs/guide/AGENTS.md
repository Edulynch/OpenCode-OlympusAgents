# User guides

- Put how-to Markdown here: help a reader complete one task. Before adding a guide, check the [existing guides](../README.md#user-guides) for overlap.
- Lead with the goal and prerequisites. Show the shortest working steps, then how to verify success and recover from common failures.
- Label examples by platform or shell when commands differ. Keep examples free of credentials, personal paths, and unpublished release URLs. State which environment you actually verified.
- Link to the technical reference for detailed contracts or option lists; do not duplicate them in the guide.
